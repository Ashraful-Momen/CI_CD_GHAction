# Next.js Complete CI/CD Note (GitHub Actions + Event Driven Architecture)

# 1. What is CI/CD ?

CI/CD means:

| Short Name | Full Meaning                     |
| ---------- | -------------------------------- |
| CI         | Continuous Integration           |
| CD         | Continuous Delivery / Deployment |

---

# 2. What is GitHub Actions ?

GitHub Actions is GitHub built-in CI/CD automation system.

It automatically runs workflow according to Git events.

---

# 3. GitHub Actions Follow Event Driven Architecture

GitHub Actions works based on:

```txt id="p93n7x"
EVENT
   │
   ▼
WORKFLOW
   │
   ▼
JOBS
   │
   ▼
STEPS
   │
   ▼
COMMAND EXECUTION
```

# 8. Important Keywords

| Keyword | Purpose              |
| ------- | -------------------- |
| name    | Workflow Name        |
| on      | Trigger Event        |
| jobs    | Collection of Jobs   |
| runs-on | Operating System     |
| steps   | Command List         |
| run     | Execute Bash Command |
| uses    | Use Prebuilt Action  |

# 31. Value Pass Workflow

```yaml id="7pcp7q"
name: Value Pass Workflow

on:
    workflow_dispatch:

        inputs:

            name:

                description: "Enter Your Name"

                required: true

                default: "unnamed"

jobs:

    first-job:

        runs-on: ubuntu-latest

        outputs:

            greeting-message:
                ${{ steps.message.outputs.text }}

        steps:

            - name: Generate Message

              id: message

              run: |

                  echo "text=Hello ${{ github.event.inputs.name }}" >> $GITHUB_OUTPUT


    second-job:

        runs-on: ubuntu-latest

        needs: [first-job]

        steps:

            - run: |

                echo "${{ needs.first-job.outputs.greeting-message }}"
```

# 32. Matrix Workflow

Matrix workflow runs jobs in parallel.

Use Cases:

* Multiple Node.js Version
* Multiple Server
* Multiple Docker Build

---

# 33. Matrix Workflow Example

```yaml id="mjlwmu"
name: Matrix Workflow

on:
    workflow_dispatch:

jobs:

    matrix-job:

        runs-on: ubuntu-latest

        strategy:

            matrix:

                node-version: [18, 20]

        steps:

            - uses: actions/checkout@v4

            - uses: actions/setup-node@v4

              with:
                  node-version: ${{ matrix.node-version }}

            - run: node -v
```

# 46. Composite Action Example

## action.yml

```yaml id="mjwtsc"
name: "Greeting Action"

description: "Simple Greeting Action"

inputs:

    name:

        description: "User Name"

        required: true

        default: "unnamed"

outputs:

    message:

        description: "Greeting Message"

        value: ${{ steps.greet.outputs.message }}

runs:

    using: "composite"

    steps:

        - name: Generate Greeting

          shell: bash

          id: greet

          run: |

              echo "message=Hello ${{ inputs.name }}" >> $GITHUB_OUTPUT
```

---

# 47. Use Composite Action

```yaml id="yjlwm3"
name: Use Composite Action

on:
    workflow_dispatch:

jobs:

    composite-job:

        runs-on: ubuntu-latest

        steps:

            - uses: actions/checkout@v4

            - name: Run Composite Action

              id: greet

              uses: ./

              with:

                  name: "Rahim"

            - run: |

                echo "${{ steps.greet.outputs.message }}"
```

# 48. Laravel + React Composite Action Example

## action.yml

```yaml id="wrjlwm"
name: "Laravel React Setup"

description: "Setup Laravel and React Environment"

inputs:

    php-version:

        required: true

        default: "8.2"

    node-version:

        required: true

        default: "20"

outputs:

    test-status:

        value: ${{ steps.test.outputs.status }}

runs:

    using: "composite"

    steps:

        - uses: actions/checkout@v4


        - uses: shivammathur/setup-php@v2

          with:
              php-version: ${{ inputs.php-version }}


        - uses: actions/setup-node@v4

          with:
              node-version: ${{ inputs.node-version }}


        - run: composer install

          shell: bash


        - run: npm install

          shell: bash


        - id: test

          run: |

              php artisan test

              echo "status=success" >> $GITHUB_OUTPUT

          shell: bash
```
