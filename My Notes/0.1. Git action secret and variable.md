# GitHub Actions Variable & Secret (বাংলায় সহজ ব্যাখ্যা)

## 1. Variable কী ?

GitHub Actions এ **Variable** হলো এমন value যেটা workflow/job/script এর মধ্যে reuse করা হয়।

এগুলো সাধারণত:

* App name
* Server IP
* Docker image name
* Port
* Environment name
* Build version

এর মতো **non-sensitive data** রাখার জন্য ব্যবহার হয়।

Example:

```yaml
env:
  APP_NAME: my-next-app
  PORT: 3000
```

Usage:

```yaml
echo $APP_NAME
```

---

# 2. Secret কী ?

**Secret** হলো sensitive/private data।

যেগুলো public হওয়া dangerous:

* VPS Password
* SSH Private Key
* API Key
* Database Password
* JWT Secret
* AWS Key
* Docker Hub Password

এসব GitHub encrypted করে রাখে।

---

# Main Difference

| Feature              | Variable | Secret   |
| -------------------- | -------- | -------- |
| Sensitive Data       | ❌ No     | ✅ Yes    |
| GitHub UI তে visible | ✅ Yes    | ❌ Hidden |
| Log এ show হয়        | ✅ Yes    | ❌ Masked |
| Encryption           | ❌ No     | ✅ Yes    |

# 8. Complete Real Example

```yaml
name: Deploy App

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Build Docker
        run: |
          docker build -t ${{ vars.APP_NAME }} .

      - name: SSH Deploy
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ vars.SERVER_IP }}
          username: root
          key: ${{ secrets.SSH_PRIVATE_KEY }}

          script: |
            cd /apps/myapp
            docker compose pull
            docker compose up -d --build
```

# 12. Why Secret Important ?

যদি আপনি password/code সরাসরি YAML এ লিখেন:

```yaml
password: mypassword123
```

তাহলে:

* GitHub এ visible হবে
* Hacker access পেতে পারে
* Public repo হলে leak হবে

তাই secret ব্যবহার mandatory।

---

GitHub:

* encrypted storage ব্যবহার করে
* logs এ mask করে
* UI তে full value দেখায় না

# 14. Best Practice

## Never Store These in Variable

❌ Password
❌ API Key
❌ Database URL
❌ JWT Secret

এসব সবসময় Secret এ রাখবেন।

---

## Variable এ রাখুন

✅ App Name
✅ Port
✅ Docker Image Name
✅ Region
✅ Non-sensitive config
